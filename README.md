# Primeiro Projeto no GitHub

Projeto acadêmico desenvolvido durante o curso de Desenvolvimento de Sistemas no Senac, com o objetivo de praticar versionamento de código com Git e GitHub, além de desenvolvimento web com HTML, CSS e JavaScript em ambiente Apache.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Apache (servidor web)
- Git / GitHub (versionamento)

## Como rodar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/nome-do-repo.git
```

2. Configure o arquivo `.env` baseado no `.env.example`:
```bash
cp ".env example" .env
# Preencha com suas credenciais
```

3. Abra o `index.html` no navegador ou configure no servidor Apache.

## Estrutura

```
/
 index.html         página principal
 contato.html       página de contato
 site.html          página do site
.env.example       modelo de variáveis de ambiente
.htaccess          configuração do Apache
.gitignore         arquivos ignorados pelo Git
 README.md          este arquivo
```
